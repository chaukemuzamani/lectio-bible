# Lectio Bible

Read the Bible in many versions side by side, with the Hebrew and Greek, word-by-word details, footnotes and highlights.

**Open it:** https://chaukemuzamani.github.io/lectio-bible/

## Install it as an app

| Device | How |
|---|---|
| Android (Chrome) | Open the link, tap ⋮ → **Install app** (or **Add to Home screen**) |
| iPhone / iPad (Safari) | Open the link, tap **Share** → **Add to Home Screen** |
| Windows / Mac (Chrome or Edge) | Open the link, click the install icon at the right of the address bar, or **Aa → Install** in the app |

Chapters you open are kept on the device. To read with no connection, open **Aa → Offline reading → Save offline** while online; it saves the selected version, the one you compare with, the Hebrew and Greek, and the word-detail lexicons.

Highlights are stored on each device.

## What's inside

- 29 Bibles: English (KJV, BSB, WEB, LSV, ASV, YLT, Geneva, Douay-Rheims and more), Messianic and Jewish (NHEB-ME, WMB, JPS 1917), Hebrew OT, Greek NT (NA28, SBL, Textus Receptus, Byzantine), Russian Synodal, Church Slavonic, Makarius, and Shona.
- Word links between the two columns; the KJV, Hebrew and Greek are hand-tagged, other versions are matched statistically and marked "≈ approximate".
- Copyrighted versions (NASB, NKJV, ESV, CJB, NIV, NLT, CSB, AMP, modern Russian and Xitsonga Bibles) open the same chapter on Bible.com.
